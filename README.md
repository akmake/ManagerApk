# Tether — פלטפורמת ניהול מכשירי אנדרואיד

## חזון המוצר

**Tether** היא פלטפורמה לניהול וחסימת מכשירי אנדרואיד, המיועדת למכשירי ילדים ומכשירים כשרים.
הפלטפורמה מאפשרת יצירת **קהילות** — קבוצות מכשירים עם פרופיל הגבלות משותף — כאשר כל קהילה קובעת בעצמה את רמת ההגבלה שהיא רוצה.

הפלטפורמה בנויה על גבי **Android Device Owner API** (Android Enterprise) — תשתית רשמית של גוגל המאפשרת שליטה מלאה על המכשיר ברמת מערכת ההפעלה, ללא צורך ב-Root.

> פלטפורמה | אנדרואיד בלבד | שלב הרצה (ללא מודל תשלום כרגע)

---

## קהל יעד

- **מכשירי ילדים** — הורים שרוצים לשלוט על מה הילד יכול להתקין ולגשת אליו
- **מכשירים כשרים** — קהילות דתיות המעוניינות בהגבלת תוכן

---

## מבנה הרשאות (3 רמות)

| רמה | תיאור |
|-----|--------|
| **סופר אדמין** | המפתח בלבד — שליטה מלאה על כל המערכת, מחליט מה מנהלי קהילות יכולים לעשות |
| **מנהל מוסמך** | מי שהוסמך על ידי הסופר אדמין — מנהל קהילות מסוימות דרך האפליקציה והשרת |
| **משתמש קצה** | בעל המכשיר — אין לו שליטה על החסימות |

---

## מודל הקהילות

- **קהילה** = קבוצה של מכשירים עם פרופיל הגבלות משותף
- דוגמאות: "משפחת כהן", "ילדי בית ספר X", "קהילת Y"
- כל קהילה מגדירה בעצמה את רמת ההגבלה שלה
- שינוי הגדרות מתפשט לכל המכשירים בקהילה בזמן אמת

---

## הצטרפות מכשיר לקהילה

כל קהילה מקבלת **קוד מזהה ייחודי** — מחרוזת של אותיות גדולות ומספרים.

תהליך ההצטרפות הוא **דו-צדדי** (לפרטיות ואבטחה):
1. המשתמש מכניס את הקוד או סורק ברקוד
2. המשתמש רואה "קהילת X מבקשת לנהל את המכשיר שלך" ומאשר בעצמו

> מנהל קהילה לא יכול להשתלט על מכשיר ללא ידיעת הבעלים

---

## הגדרות שמנהל קהילה יכול לקבוע

### חסימות התקנה
- האם Google Play חסום או פתוח
- רשימת אפליקציות מותרות (whitelist)
- רשימת אפליקציות אסורות (blacklist)
- מספר מקסימלי של אפליקציות שמותר להתקין

### התנהגות בעת פעולה חסומה
מנהל הקהילה בוחר מה יקרה כשמשתמש מנסה לבצע פעולה חסומה:
- **חסימה שקטה** — הפעולה נחסמת בלי הודעה
- **הודעת שגיאה** — "פעולה חסומה על ידי מנהל המערכת"
- **בקשת אישור** — המשתמש שולח בקשה למנהל, שיכול לאשר או לדחות (מייצר התראה למנהל)

### לוגים והתראות
- הסופר אדמין מחליט האם מנהלי קהילות יכולים לצפות בלוג פעולות
- לוג כולל: מי ניסה מה ומתי

## ממשק ניהול למנהל קהילה

- **אפליקציה אנדרואיד** — ממשק ניהול מלא עם כל האופציות
- **שרת (Web)** — גישה נוספת לניהול מרחוק

## עבודה אופליין / אונליין

- **אונליין** — המכשיר מסונכרן עם השרת, מקבל עדכוני הגדרות בזמן אמת
- **אופליין** — החסימות ממשיכות לפעול גם ללא חיבור לאינטרנט (הגדרות שמורות מקומית)

## יכולות טכניות (Android Device Owner API)

| יכולת | תיאור |
|-------|--------|
| `DISALLOW_INSTALL_APPS` | חסימת התקנת כל קובץ APK מכל מקור |
| `setApplicationHidden` | הסתרת אפליקציות (Google Play, דפדפן וכו') |
| `DISALLOW_SAFE_BOOT` | חסימת מצב בטוח (מונע עקיפת החסימות) |
| `DISALLOW_FACTORY_RESET` | חסימת איפוס יצרן |
| `DISALLOW_USB_FILE_TRANSFER` | חסימת העברת קבצים דרך USB |
| `setLockTaskPackages` | מצב קיוסק — נעילה על אפליקציה אחת |
| Remote Wipe | מחיקת מכשיר מרחוק |
| Silent Install | התקנת אפליקציות ברקע בלי אישור המשתמש |

## אופן הפעלת Device Owner על מכשיר

### אפשרות א' — כבל USB (למכשירים בודדים)
1. מחיקת כל חשבונות גוגל מהמכשיר
2. התקנת האפליקציה כרגיל (APK)
3. חיבור למחשב + הפעלת USB Debugging
4. הרצת פקודה אחת ב-ADB:
   ```
   adb shell dpm set-device-owner com.tether.app/.TetherAdminReceiver
   ```

### אפשרות ב' — קוד QR (לכמויות גדולות)
1. איפוס המכשיר לגדרות יצרן
2. לחיצה 6 פעמים במסך הראשון
3. סריקת קוד QR שמכיל את פרטי ההתקנה
4. המכשיר מתקין ומגדיר הכל אוטומטית
