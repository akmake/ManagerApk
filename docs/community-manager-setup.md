# ניהול עצמאי של קהילות

## הפעלה

השינוי כולל את אפליקציית ManagerApk ואת השרת והאתר בפרויקט sterni.
כדי להשתמש בו במערכת הפעילה יש לפרוס את שינויי השרת והאתר ולהתקין את האפליקציה המעודכנת.
השינויים המקומיים אינם פריסה למערכת הפעילה.

## יצירת מנהל קהילה

1. התחבר עם חשבון מנהל־על.
2. באפליקציה פתח **מנהלי קהילות ושיוך קהילות**. באתר פתח את לשונית **מנהלים**.
3. בחר **צור מנהל קהילה** והזן שם, אימייל וסיסמה של לפחות שמונה תווים.
4. בחר קהילה קיימת ואשר את יצירת החשבון והשיוך.
5. מסור למנהל את פרטי הכניסה באופן פרטי. האימייל משמש כשם המשתמש.

מנהל הקהילה נכנס לאזור המנהל באפליקציה או לנתיב `/tether` באתר, בלי חשבון באתר הראשי.
הוא מקבל גישה לכל מכשירי הקהילות ששויכו אליו, כולל המכשירים הקיימים.
קוד הקהילה וההגדרות נשמרים. מנהל־העל ממשיך לקבל גישה לכל הקהילות.

## מנהל קיים והחלפת מנהל

באזור שיוך הקהילות ניתן לבחור מנהל פעיל לכל קהילה.
שינוי השיוך מעביר את השליטה מהחשבון הקודם לחשבון שנבחר.
לחשבון אחד אפשר לשייך כמה קהילות.
ביטול גישה של מנהל מבטל את גישת החשבון בשרת; מנהל־העל יכול לשייך מחדש את הקהילות שלו.

## בדיקות לפני שימוש במערכת הפעילה

- חשבון מנהל חדש רואה רק את קהילותיו ומצליח לשנות מדיניות של מכשיר בהן.
- שינוי שיוך הקהילה מסיר את הגישה של המנהל הקודם.
- מעבר מהיר מערוץ וואטסאפ לחיפוש אינו מבטל חסימה שכבר זוהתה.
- גם כשהמקלדת פתוחה, האכיפה מוציאה מחיפוש הערוץ.
- צ׳אטים רגילים זמינים לאחר חזרה לרשימת הצ׳אטים.

בדיקות אוטומטיות עברו עבור שישה תרחישים באפליקציה ותשעה תרחישי הרשאות בשרת.
בדיקות השרת מפעילות את קוד הנתיבים עם מסד נתונים מדומה; הן אינן בדיקת מערכת מול מסד הנתונים הפעיל.
הבניות אינן מחליפות בדיקת וואטסאפ על גרסת האפליקציה שבמכשיר.
